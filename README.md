## 🚀 Project Overview

**Nexus** is an enterprise-grade logistics and fulfillment engine designed to synchronize global retail operations. Built using **Spring Boot REST APIs** and **Firebase Cloud (Firestore)**, the system connects branch inventory hubs, dynamic pricing strategies, order lifecycle workflows, and legacy supplier integrations into a single synchronized operational engine.
